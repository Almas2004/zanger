# ZANGER CONSULTING GROUP

Статический сайт юридической компании на чистом HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` напрямую в браузере или через Live Server.

## Где менять данные

- Контакты и адреса: `js/config.js`
- Услуги: `js/services-data.js`
- Стили: папка `css/`
- Изображения: `assets/images/`

## Публикация на GitHub Pages

Загрузите все файлы из корня репозитория в ветку GitHub Pages. Сборка не требуется.
